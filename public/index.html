CONSTANCIA DE COLABORACIÓN

Tecnologías y herramientas

  • JavaScript y Node.js 20 o superior: lógica del servidor y del navegador mediante módulos ES.
  • Express: servidor web, archivos estáticos y endpoint HTTP para las consultas.
  • OpenAI JavaScript SDK: conexión con Responses API y búsqueda directa en OpenAI Vector Store.
  • Vector Store: recuperación semántica de fragmentos documentales; el servidor solicita hasta 12 resultados relevantes antes de generar una respuesta.
  • JSON Schema estructurado: respuestas separadas en afirmaciones, tipo, fuente, extracto y referencias jurídicas.
  • HTML, CSS y JavaScript del navegador: interfaz adaptable, formato Markdown seguro, animaciones y controles del chat.
  • Python 3 y herramientas de PDF: extracción local de metadatos, inventario JSONL y, si está disponible, propiedades con Poppler pdfinfo.
  • dotenv y variables de entorno: configuración local de credenciales, modelo e identificador del Vector Store.

Métodos y procesos aplicados

  1. Inventario de documentos PDF y extracción de metadatos útiles para identificar la fuente, su tipo, jurisdicción, páginas y huella SHA-256.
  2. Recuperación de fragmentos relevantes desde el Vector Store antes de redactar cada respuesta.
  3. Instrucciones de fundamentación jurídica que separan texto expreso, interpretación, recomendación y límites de verificación.
  4. Validación en servidor de las citas: el extracto debe existir en el fragmento recuperado y los artículos citados deben aparecer en la evidencia correspondiente. Si la validación falla, la respuesta se bloquea.
  5. Evaluaciones por casos dirigidos a artículos y pruebas automatizadas de referencias legales para detectar citas incorrectas y respuestas no sustentadas.
  6. Revisión de calidad basada en informes de evaluación y ajustes iterativos del flujo de recuperación, generación y presentación.

Esta constancia reconoce el trabajo descrito en el desarrollo del prototipo. La aplicación ofrece apoyo de consulta documental; sus resultados deben cotejarse con las fuentes originales.

¿Qué puedes consultar?

El asistente puede buscar y explicar, con base en los fragmentos recuperados:

  • Protección de datos personales, deberes de seguridad y atención de vulneraciones.
  • Delitos informáticos y acceso o uso no autorizado de sistemas.
  • Obligaciones y marco regulatorio aplicable a telecomunicaciones, instituciones financieras y sujetos obligados.
  • Procedimientos penales, criterios judiciales, precedentes y tesis incluidos en el acervo.
  • Infraestructura crítica, coordinación de incidentes y cuestiones técnicas descritas por los documentos.
  • Comparaciones entre disposiciones, siempre que los extractos recuperados permitan verificarlas.

La respuesta se limita a la evidencia recuperada: si los documentos no permiten verificar un dato o una cita, el asistente debe señalar esa limitación. La lista describe los archivos fuente del proyecto; la disponibilidad efectiva depende de que estén cargados en el Vector Store configurado.
